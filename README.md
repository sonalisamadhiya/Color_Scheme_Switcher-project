🎨 Color Switcher Website

A simple and interactive Color Switcher web app built with HTML, CSS, and JavaScript.
This project allows users to change the background color of the page dynamically with just a click.

🚀 Features
Switch between different colors with a single click
Smooth background color transitions
Simple, minimal, and responsive design
Built with pure HTML, CSS, and JavaScript (no frameworks)

🛠️ Technologies Used
HTML5 – Structure of the webpage
CSS3 – Styling and animations
JavaScript (ES6) – Logic for color switching
